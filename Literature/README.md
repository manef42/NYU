This is the Research Papers used in making this project.
- papier_augustin.pdf is the justification of the importance of predicting fire and flame spread in deep space missions.
- Karniadakis_nature.pdf and PINNs.pdf are the founding papers of using Physics informed machine learning techniques to regression.
- tabular_data.pdf is a paper that justifies why for data like this case (tabular) xgboost models out perform neural networks.
- Jose.pdf is the only paper in literature that tries to predict flame spread rate using machine learning, so this work benchmark it.
