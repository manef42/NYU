\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Spacecraft fire safety requires material decisions under atmospheric, flow,
geometric, and gravitational conditions for which direct testing is expensive
and unevenly distributed. This report consolidates the project's curated
literature database and evaluates whether supervised machine learning can
support two tasks: binary prediction of sustained ignition and regression of
flame-spread rate (\FSR). The evaluation deliberately separates interpolation
among conditions represented within known papers from extrapolation to entire
held-out papers. After deduplication, the ignition task contains 4,487
observations from 87 canonical papers; the \FSR{} task contains 2,531 usable
observations from 66 papers. Preprocessing, hyperparameter search, threshold
selection, and augmentation are confined to training partitions.

For ignition, the selected row-level XGBoost model reaches a
ROC--AUC of \(0.9076\pm0.0102\), whereas the selected unseen-paper XGBoost
model reaches \(0.7183\pm0.0444\). For \FSR{}, the selected random forest
reaches \(R^2=0.8790\pm0.0178\) and
RMSE \(=0.0063\pm0.0005~\si{\metre\per\second}\) for row-level
interpolation; paper-grouped evaluation falls to
\(R^2=0.4576\pm0.2215\) and
RMSE \(=0.0122\pm0.0041~\si{\metre\per\second}\).
SHAP and permutation analyses identify oxygen, flow and transport quantities,
thermal time scales, and fuel properties as important model inputs, but these
associations are not interpreted causally. The central engineering result is
therefore conditional: the database supports useful within-domain ranking and
screening, but the generalisation gap and source heterogeneity preclude using
the models as stand-alone certification evidence. The models are positioned as
traceable decision-support tools for prioritising tests, identifying poorly
covered regimes, and guiding database expansion.
